## INVALID_LEDGER_NUMBER 修正

사용자 제공 공식 명세의 FcurrTaxSumAmt는26.6인데 공통 정규식이 소수4자리만 허용하던 불일치를 수정했다. 필드별 자릿수를 적용하고, JSON 숫자 원문의 지수표기/문자열 바깥 공백/+부호를 십진 문자열로 정확히 변환한다. Number로 금액을 재파싱하거나 반올림하지 않는다. 빈값/null은0으로 바꾸지 않고 기존 결측 검증을 유지한다. 소수6자리·큰 정수·정확한 지수표기·암호화 후 재조회·과다 정밀도/잘못된 형식 거절 회귀 테스트를 추가했다. 실패 시 허용된 숫자 필드명만 전달하며 실제 값은 노출하지 않는다. 사용자 요청에 따라 최초 수집 시작일은2026-10-01로 설정하며, 이전 보유 원가가 없는 매도는 수익으로 추정하지 않는다. 전체 과거수집/자동수집 성공은 별도 확인이 필요하다.
