# t0150 daily journal

Source: owner-supplied official LS request example and 33 response fields, received 2026-10-21. Endpoint POST /stock/accno, read-only TR t0150. Fields: OutBlock mdqty/mdamt/mdfee/mdtax/mdargtax/tmdtax/mdadjamt/msqty/msamt/msfee/tmstax/msadjamt/tqty/tamt/tfee/tottax/targtax/ttax/tadjamt plus four cts_* cursors; OutBlock1 medosu/expcode/qty/price/amt/fee/tax/argtax/adjamt/middiv.

Enabled only with ENABLE_T0150=true in DAILY_1630 mode. Uses existing sync lease and same transient OAuth token/session as completed ledger page. If ledger was already collected today, fetch only journal. Complete same-day journals are reused. Initial CTS values empty (not sample placeholder "1"); on continuation echo output CTS and tr_cont headers; >=600ms between pages (quota 2/sec), <=40 pages/10,000 rows/55 seconds between requests. Partial/failed runs never overwrite last complete journal and may restart pagination on retry; no per-page durable checkpoint. Existing ledger completion is independent of journal success.

Only fully completed, date-consistent journal is published in encrypted account_state using existing AES-GCM. Cursors remain transient. No new schema, credentials, access rules or public site changes. Response is still owner-authenticated/no-store. Latest journal retained, not a cumulative fill ledger. Source date and collection timestamp visible; this is a 16:30 snapshot, not a guarantee that later NXT trades are included.

Official aggregate values are authoritative and validated for costs and settlement. Detail and subtotal rows displayed as provided, never summed together or inserted into the moving-average engine. Numbers outside JS safe integer range or missing cost fields block publication. Unknown numeric side codes are not inferred. Symbol labels remain source codes because no stock-name field exists here. Market coverage is not inferred from media field.

There is no acquisition cost / realized PnL field. Net settlement difference is cash movement, not investment profit. Existing ledger-derived PnL remains separate and may still require historical cost.

Validation: synthetic tests for cost/settlement, subtotal non-duplication, missing/unsafe amounts, encrypted storage, continuation failure, preserved prior snapshot, and same-day idempotency. Actual live provider acceptance remains to be verified through the owner's authenticated UI after scheduled run.

## Prior-date request (2026-10-21)

Owner requested 2026-10-20 first. t0151 request/response verified against locally cached LS official catalog examples (specs/apis/37d22d4d-83cd-40a4-a375-81b010a4a627.json in ls-api-reference). Request uses t0151InBlock.date=YYYYMMDD and the same four CTS fields; response blocks t0151OutBlock / t0151OutBlock1. No extrapolation of PnL fields.

JOURNAL_BACKFILL_DATE selects a specific prior date. Within the existing 16:30 scheduler/lease window, incomplete prior-date snapshot is queried before today's ledger/journal. It is stored independently in encrypted journalPrevious state. Snapshot is reused after completion. Failure records journalPreviousError without overwriting either journal; next authorized window can retry. No historical date is passed to t0150. Date syntax, calendar validity and past-only bounds validated before network. UI defaults to available prior-date snapshot; buttons switch between prior and current snapshots. Daily background collection remains 16:30; no session-hour restriction is bypassed.
