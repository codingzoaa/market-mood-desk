# 저장된 국내 보통매매 원장 → 계좌 분석

34건의 암호화 원장이 저장되어 있으나 LS_LEDGER_RULES가 없어 모든 거래가 CLASSIFICATION_REQUIRED로 막히는 문제를 수정한다. 외부에서 원장을 복호화하거나 키를 추출하지 않는다. 보호된 /api/account 요청 내에서 기존 loadLedger가 복호화한 자료만 계산하며 공급자 호출과 DB 쓰기를 추가하지 않는다.

확인 근거는 사용자가 화면에서 제시한 구분명 매수/매도 및 보통매수_KRX/NXT, 대응하는 보통매도_KRX/NXT와 제공된 CDPCQ04700 공식 필드 명세다. 사용자 실제 종목·거래금액·계좌번호는 코드·테스트·문서에 포함하지 않는다. 합성 테스트만 사용한다.

기본 규칙 버전 LS_ORDINARY_CASH_KRX_NXT_V1: 구분명과 적요의 매수/매도가 일치하는 국내 보통매매만 허용한다. 정상/비취소 표시와 원거래번호0·대출일자 없음이 필요하며 취소/정정/신용/외화 또는 모르는 적요는 검토 대기다. 명시적인 국내 시장 적요와 국내 종목코드가 있는 경우 빈 통화코드는 국내 원화 거래로 해석한다. 원화 외 통화나 외화금액이 있으면 거부한다. A접두/6자리 종목코드만 정확히 정규화해 KRX·NXT를 같은 계좌·종목으로 합친다.

거래금액은 TrdAmt, 수수료는 CmsnAmt, 총세금은 TaxSumAmt만 사용한다. 업로드된 공식 명세에서 TaxSumAmt 이름은 세금합계금액으로 확인했다. 거래세·제세금 등을 합계에 다시 더하지 않으며 합계가 누락되거나 개별 세금보다 작은 모순은 검토 대상으로 둔다. 가격은 평균단가일 수 있어 수량×가격으로 원장 거래금액을 재작성하지 않는다. 처리시각은 체결시각으로 간주하지 않고 원장 순번으로 정렬한다.

이동평균 취득원가: 매수금액+매수비용 누적, 매도 실현손익=매도금액−매도비용−매도수량의 평균원가. 원가 이전 기록이 없는 매도는 이익에 넣지 않고 불완전 보유로 표시한다. 원가가 확인된 매도가 하나도 없으면 앱에서 실현손익과 흐름을 미확정으로 표시한다. 입출금·주식이체·배당 등은 이 보통매매 기본 규칙으로 임의 분류하지 않는다.

운영자 명시 LS_LEDGER_RULES가 있으면 기존 정확 매칭 규칙이 우선한다. 설정이 잘못되면 기본 규칙으로 우회하지 않는다. 한 건이라도 미검증 거래가 있으면 손익 합계는 기존과 동일하게 보류한다. 안전하게 분류된 매매 내역은 표시하고 검토 사유를 사람에게 읽히는 문구로 제공한다.

새 UI에 저장 원장/연결 매매/확인 필요 건수와 매수·매도 개수를 표시한다. 당일 신규 거래 수집 스케줄은 평일16:30 그대로이며 저장된 원장 분석은 재조회 없이 즉시 수행한다. Access·암호화·키·DB 스키마·계좌 동기화·공개 시세 Worker는 변경하지 않는다.

검증: KRX/NXT 합산과 이동평균 원가/부분매도, 총세금 중복 합산 방지, 취소/외화/세금 결측 제외, 암호화 저장 자료의 보호된 API 연결, 계좌 식별자 미노출, 기존 인증/동기화/계좌 UI 회귀 테스트. 실제34건의 분석 결과는 아직 외부에서 확인하지 않았으며, 배포 후 소유자 로그인 화면에서 연결 건수와 검토 항목을 확인해야 한다.
