# 테마 중복과 시장 요약 개선

구성 종목이 같은 테마가 순위 여러 줄을 차지하던 문제를 줄입니다. 테마별 균등 배분은 유지하고, 선택 범위에서 구성 종목 집합이 완전히 같은 테마만 묶어 배분 대금을 합칩니다. 일부 종목만 겹치는 테마와 미분류는 합치지 않습니다. 원래 테마 검색은 유지합니다.

- 주도 섹터 목록, 오늘의 주도주 요약, 캘린더의 대표 테마에 적용합니다.
- 단일 종목/동반 강세와 최대 종목의 원 거래대금 비중을 표시합니다.
- 첫 화면에 코스피·코스닥 시장 폭, +4% 종목 대금 집중도, 수집 일반주 테마 분류율을 표시합니다.
- 순위 제목에 +4% 표본임을 명시합니다. 전체 시장 자금 유입으로 해석하지 않습니다.

## 범위와 한계

같은 구성 종목을 묶는 것은 표시 중복 제거이며 산업 분류 확정이나 검증된 종합점수가 아닙니다. 대표 명칭은 기존 배분 대금 순 첫 테마이고 다른 명칭도 함께 표시합니다. 단일 종목에 여러 테마가 있으면 통합 행의 대금이 기존 개별 테마보다 커지지만 전체 배분 대금 합계는 보존됩니다.

로테이션 시계열은 날짜마다 구성 종목이 달라지므로 기존 개별 테마 기준을 유지합니다. 업종 원천 데이터 보완, 전체 시장과 강세 표본 대금 분리, RVOL/최근 5분 대금, 데이터별 지연 원인 안내는 후속 작업입니다. 과거 원장과 Worker/DB는 수정하지 않습니다.

## 검증

로컬에서 테스트 70개, TypeScript 검사, production 빌드 통과. 테스트에는 5개 테마 단일 종목 중복 제거, 대금 보존, 일부 겹침 유지, ETF 제외 분류율, 지수와 시장 폭 괴리, 첫 화면 요약 렌더링이 포함됩니다. 의존성은 환경에 설치된 패키지를 사용했습니다. 정확한 lockfile의 npm ci와 실제 브라우저의 시각적 확인은 별도 확인 항목입니다.

운영 병합/배포는 하지 않았습니다. Pages 워크플로는 PR에서 검증만 하고 main에서 배포합니다.
