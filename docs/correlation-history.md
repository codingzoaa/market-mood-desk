## 코스피 일봉 캔들 연결

상관관계 하단 차트는 날짜별 종가 선과 실제 OHLC 캔들을 함께 표시한다. 산점도와 캔들/종가 점은 같은 날짜 선택을 공유하며 클릭·Enter·Space로 이동한다. 선택한 날짜의 시가·고가·저가·종가, 등락률, 개인 순매수와 원천을 표시한다. 빨강/파랑은 전일 대비가 아닌 **시가 대비 종가**의 상승/하락이다. OHLC가 없거나 검증에 실패하면 종가만 남긴다.

수집기는 기존 t1511 응답의 openjisu/highjisu/lowjisu/pricejisu를 선택적으로 저장한다. 새 TR이나 새 스케줄, DB 테이블은 추가하지 않는다. 정상적인 15:30–16:10 마감 관측 또는 기존 검증된 보충 기록만 공개하며 장중 OHLC는 종가 일봉으로 내보내지 않는다. 값 누락·0·NaN·고저 역전·종가 불일치는 캔들에서 제외하지만 기존 지수·수급은 유지한다.

DB 쓰기나 LS 추가 호출 없이 기존 원문을 재사용한다. API 응답 크기는 기존 클라이언트 제한(150KB)을 유지한다.
