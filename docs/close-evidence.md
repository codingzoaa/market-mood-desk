# 강세 섹터 캘린더 · LS 마감 점수 자료

## 연결 범위

초기 대상은 SK하이닉스(000660), 삼성바이오로직스(207940), 삼성E&A(028050), 컨텍(451760), 진양화학(051630)이다. `shared/close-targets.mjs`의 코드·이름을 LS 응답과 일치시켜 수집하며, 신규 대표종목을 선정하면 이 목록도 검증 후 갱신한다. 거래대금 상위 목록에서 찾을 수 없는 종목도 별도로 조회한다.

- t1102: KRX 정규종가, 현재가, 거래량, 상장주식수(천), 시가총액을 확인한다. 시가총액은 `total × 1억 원`과 `정규종가 × listing × 1천주`를 대조한다.
- t8410: 같은 거래일의 일봉·거래대금·종가 이력. 거래대금은 백만원→원 변환 후 거래량×저가~고가 범위와 대조한다. 현재가·정규종가·일봉 종가, 거래량과 대금도 일치해야 한다.
- t1702: `volvalgb=0`, `msmdgb=0`, `gubun=0`, `exchgubun=K`. 해당일 외국인·기관 금액 순매수. 요청일·종가·거래량·거래대금을 이미 고정한 정규장 자료와 대조한다. 백만원→원 변환 후 투자주체 합계 오차 및 거래대금 상한을 검사한다. 전 주체 0은 집계 대기로 처리한다.

공식 문서: https://openapi.ls-sec.co.kr/apiservice 에서 각 TR 검색. t1717은 순매수 수량/단가이므로 금액 수급으로 대입하지 않는다.

## 마감과 시간외 분리

실제 운영 저장자료에서 16:10 현재가가 뉴스의 정규장 종가와 다른 사례를 확인했다. 기존 스냅샷을 점수의 종가 원장으로 재사용하지 않는다. 새로운 시총·대금 원장은 한국시간 평일 15:30~15:39 사이에만 고정한다. 수급은 기존 수집 제한인 16:10까지 재시도하되 정규장 거래량·대금 일치 검사를 통과한 경우에만 채택한다. 시간외 포함 자료는 탈락한다. 수급은 수집 시점의 집계이며 이후 갱신될 수 있다. 기존 국내 수집기 시간과 정책은 바꾸지 않는다.

한 번에 2종목, 종목당 최대 4회 재시도, TR 사이 1.1초 간격. 별도 D1 lease를 사용한다. 원장 키는 `close-evidence:YYYY-MM-DD`, 완료 항목은 재수집하지 않는다. 기존 스냅샷·지수·ETF 원장은 보존한다. 휴장·날짜 미확인·단위 불일치는 점수를 만들지 않는다.

## 화면과 API

`GET /api/close-evidence?date=YYYY-MM-DD`는 저장된 검증 자료만 읽는다. HTTP 조회로 LS 수집을 실행하지 않으며, 앱키·토큰·LS 응답 원문은 반환하지 않는다. CORS와 날짜 검사는 기존 API 정책을 따른다. 화면은 날짜가 바뀌면 이전 요청을 취소하고 해당 날짜·해당 대표종목 자료만 합친다. 실패·미배포·미수집 시 편집 리뷰와 확인된 뉴스 점수는 유지한다.

지속성은 일봉으로 최대 5거래일 연속 상승을 계산하며, 하락 또는 보합까지 확인하기 전에 이력이 끝나면 미산출한다. 동반 상승은 `scoreUniverse`에 사전에 확정한 전체 구성종목이 있고 모든 구성종목의 해당일 검증 자료가 있을 때만 계산한다. 현재 편집 섹터에는 구성 원장이 없으므로 전체 구성종목 확정 대기로 표시한다. 기사에 나온 동반 종목 예시는 분모로 사용하지 않는다. 뉴스·공시 평가는 기존 출처 확인 기록을 유지한다. 5개 항목이 모두 확인되기 전에는 총점을 만들지 않는다.

## 배포·실데이터 검증

1. 테스트, TypeScript 검사, 정적 사이트와 Worker 번들을 빌드한다.
2. 기존 Cloudflare Worker에 인증한 뒤 `worker/wrangler.jsonc`로 배포한다. 기존 D1·Durable Object 바인딩과 Secret을 유지한다. Secret을 GitHub나 클라이언트로 복사하지 않는다.
3. 다음 거래일 수집 후 읽기 API로 날짜·종목·정규종가·시총·대금·수급을 대조한다. 이번 코드는 아직 LS 원격 TR로 실검증하지 않았다.
4. 서버 배포 및 읽기 경로 확인 후 Pages 화면을 배포한다. 새 서버가 배포되기 전에는 연결 완료라고 보고하지 않는다.

CLI: `wrangler deploy --config worker/wrangler.jsonc` (인증 필요).
검사: `npm test`, `tsc --noEmit`, `npm run build`.
