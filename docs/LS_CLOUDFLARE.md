# LS증권 + Cloudflare 연결

## 준비된 구성

- 웹사이트: https://codingzoaa.github.io/market-mood-desk/
- 전용 Worker: `market-note-ls-api` (기존 market-brief-api와 별도)
- 시세 API: https://market-note-ls-api.kby0991.workers.dev
- D1: `market-note-ls` / 바인딩 `DB`, 스키마 적용 완료
- GitHub에는 서버 소스와 프런트엔드만 저장합니다. LS 키·시크릿·접속 코드는 포함하지 않습니다.

## 최초 설정: Cloudflare에 Secret 3개 등록

Cloudflare 대시보드 → Workers & Pages → **market-note-ls-api** → Settings → Variables and Secrets → Add.
아래 항목을 모두 **Secret** 유형으로 등록하고 적용/배포합니다.

| 이름 | 값 |
| --- | --- |
| `LS_APP_KEY` | 발급받은 LS OPEN API 앱키 |
| `LS_APP_SECRET` | 발급받은 LS OPEN API 시크릿 |
| `DASHBOARD_TOKEN` | 직접 생성한 32~256자 무작위 사이트 접속 코드 |

설정 바로가기:
https://dash.cloudflare.com/78961f2ddb841df708b3a777fdcc94c2/workers/services/view/market-note-ls-api/production/settings

LS 앱키·시크릿은 채팅, GitHub, 웹사이트 입력란에 넣지 않습니다. 접속 코드는 LS 키와 다른 값을 사용합니다. 접속 코드를 아는 사람은 이 서버의 저장 시세를 조회할 수 있습니다. 웹사이트 시세 데이터 공개 권한은 공급자 약관을 확인하세요.

## 웹사이트 연결

1. 웹사이트 우측 상단 데이터 아이콘 → **데이터 관리** → **LS증권 시세 연결**.
2. `DASHBOARD_TOKEN`에 등록한 사이트 접속 코드를 입력하고 **시세 연결**.
3. 처음에는 서버 연결/수집 대기가 표시될 수 있습니다. 장중 5분 이내 첫 수집 후 화면은 60초마다 저장 결과를 확인합니다.
4. 접속 코드는 현재 탭의 sessionStorage에 보관합니다. LS 키는 브라우저로 전달하지 않습니다. 탭을 새로 열면 다시 입력할 수 있습니다.
5. 연결 해제 시 파일 기반 기록으로 돌아갑니다. LS 연결 중 파일 가져오기는 중지합니다.

## 수집 범위와 한계

- KRX 기준 코스피·코스닥의 거래대금 순위: t1463, 시장별 최대100개 / 최대5페이지. 회당 응답 크기에 따라 실제 종목 수가 적을 수 있습니다. 전체 상장종목 수집이 아닙니다. ETF 등이 포함된 LS 반환 범위를 기준으로 합니다.
- `value`는 백만원 → 원으로 변환합니다. `sign`으로 하락 등락률 부호를 적용합니다.
- 코스피·코스닥 지수: t1511, 001/301. 해외 지수·환율·SOX·금리·위험점수는 만들지 않고 빈 상태로 둡니다.
- 테마: t1532. +4% 종목 중 미보강 종목을 대금 순으로 최대12개/회 조회합니다. 하루 캐시를 사용하며 미수집 종목은 미분류입니다.
- ETF 패널은 위 수집 결과에 들어온 KODEX만 대상으로 합니다. 전체 KODEX 시장 순위가 아닙니다.
- 5분 수집 크론: `*/5 0-5 * * MON-FRI`와 `0-30/5 6 * * MON-FRI`. KST 평일 09:00–15:30이며 15:30분의 마감 수집을 포함합니다. 15:31부터는 신규 LS·네이버 요청, HTTP 조회에 따른 알람 예약, 기존 알람의 수집 재개를 모두 중단합니다. 진행 중인 시장 데이터 요청에도 마감 분 종료 시각의 타임아웃을 적용하며, 종료 시각을 넘긴 응답으로 정상 저장 기록을 덮어쓰지 않습니다. t8410 삼성전자 KRX 일봉의 최신 날짜와 장시작 시간을 확인해 휴장일·개장 전 값을 오늘 날짜로 저장하지 않습니다. LS 응답 형식 변경·거래정지·특수 일정 등은 실응답으로 검증이 필요합니다.
- 같은 날의 최신 관측 스냅샷을 갱신하며 과거 날짜는 365일 보관합니다. 기존 28일 기록을 소급 생성하지 않습니다. 정규장 최종 확정 데이터라고 표시하지 않습니다. 연결 시점부터 캘린더가 쌓입니다.
- 웹 조회는 저장 기록만 읽으며, 정규 수집 시간 안에서만 Durable Object 알람을 예약합니다. 실제 수집은 알람 또는 크론의 독립 실행에서 수행해 HTTP 응답 후 30초 제한을 피합니다. 웹사이트가 닫혀 있어도 Cloudflare 크론은 실행됩니다. 무료/유료 사용량 한도는 계정 설정을 따릅니다.
- DB 전역 lease는 백그라운드 알람·크론을 합쳐 최대5분당 한 수집으로 제한합니다. 실패도 이 간격을 사용합니다. 토큰 발급과 시세 조회는 같은 TLS 연결에서 처리합니다. 새 수집마다 토큰을 서버 메모리에서만 사용하며, 다른 출발 IP의 토큰 캐시를 재사용하지 않습니다. 수집 오류 시 정상 시세를 삭제하지 않습니다.

## 운영 확인

`/health`는 Worker 설정 여부만 알려주며 LS 인증 성공을 의미하지 않습니다. 실제 인증·TR 응답·단위·화면 값은 Secret 등록 후 확인해야 합니다. `/api/status`는 접속 코드를 Authorization Bearer 헤더로 보낸 요청만 허용합니다. 키나 토큰을 URL 쿼리에 넣지 마세요.

프런트엔드 변경은 GitHub Actions를 통해 GitHub Pages로 자동 배포합니다. Worker 변경은 별도 배포 대상입니다. 현재 초기 Worker는 직접 배포되어 있으며 GitHub 자동 배포와 연결되어 있지 않습니다. 로컬에서 Cloudflare 인증 후 다음을 실행할 수 있습니다.

```sh
npx wrangler@4.92.0 deploy --config worker/wrangler.jsonc
```

기존 Secret을 삭제하거나 코드·설정 파일에 넣지 마세요. 소스의 `worker/schema.sql`은 현재 DB에 적용된 테이블 정의입니다.

## 국내 시장 요약 · 업종 히트맵 · 투자자 동향

- 코스피·코스닥 요약 카드는 t1511의 지수, 전일 대비, 상승(highjo)·보합(unchgjo)·하락(lowjo) 종목 수를 사용합니다. 상·하한 종목 수를 별도로 더하지 않습니다.
- 우측 지수 추이는 t8409의 해당 거래일 5분 종가입니다. 차트가 제공되지 않으면 임의의 곡선을 만들지 않습니다.
- `오늘의 시장`은 두 현물 시장의 외국인·기관계·개인 순매수를 합산합니다. 감정·좋아요 판단은 하지 않습니다. 상세 화면은 코스피, 코스닥, KOSPI200 선물·콜옵션·풋옵션을 분리합니다. 금융투자는 기관계의 부분집합입니다.
- 히트맵은 네이버 증권 KRX 종목 목록의 시가총액 비중과 등락률, 네이버 업종 구성 종목을 사용합니다. 네이버 공개 웹 API이며 별도 API 키를 사용하지 않습니다. 업종 분류는 24시간 캐시하고, 시세는 장중 5분 수집합니다.
- 업종 목록은 `/api/domestic/market/upjong/list`, 구성 종목은 `/api/domestic/market/upjong/{no}/stocklist`의 시장별 cursor, 전체 종목 시세는 `/api/domestic/market/stock/default`의 PAGE_INDEX를 사용합니다. 빈 페이지·hasNext=false까지 확인하고 중복·형식 오류가 있으면 마지막 정상 결과를 유지합니다.
- 첫 업종 구성 수집은 여러 Durable Object 알람으로 나눕니다. 한 번에 구성 종목 요청을 24회 이하로 처리해 무료 Worker의 외부 요청 한도를 고려합니다. `완만하게`는 종목 시가총액의 제곱근, `시가총액`은 원래 비중, `업종 같은 크기`는 업종 면적을 동일하게 배분합니다. 업종 등락률은 표시 종목의 시가총액 가중평균입니다.
- 시장 상세는 기존 종목 스냅샷과 독립적으로 저장합니다. `/api/market-details?date=YYYY-MM-DD`는 기존 접속 코드·Origin 검증을 동일하게 적용합니다. 조회 실패를 0이나 가상 데이터로 바꾸지 않습니다. 수집 시각과 마지막 정상 값 유지 여부를 화면에 표시합니다.
- 장 마감 뒤나 다음 날 개장 전 처음 연결할 때는 마지막 저장 거래일만 조회하며 새로운 시세를 수집하지 않습니다. 다음 거래일 장중에 이전 날짜의 현물 지표를 새로 덮어쓰지 않습니다.

2026-10-19 실제 데이터 검증: 코스피 5,768.01·코스닥 808.89, 각 77개의 당일 5분 지수 관측값, 네이버 업종 79개와 코스피 942개·코스닥 1,821개(총 2,763개) 종목이 수집·검증되었습니다. 업종 미분류는 0개였습니다. t1601 금액 모드의 원본 값을 억원으로 보존하며 t1463의 백만원→원 변환을 적용하지 않습니다. 같은 거래일 코스피 외국인 순매수 947은 네이버 지수 투자정보의 +947억원과 대조했습니다. 제공사별 집계 시각·분류 차이가 있으므로 LS 수급을 네이버 수급으로 섞어 덮어쓰지 않습니다. 차트·히트맵·수급 전체 페이로드는 프런트엔드 검증기를 통과해야 표시됩니다.

최종 실제 수집(2026-10-20 00:23 KST, 거래일 2026-10-19)에서 상세 수집 오류가 없는 상태를 확인했습니다. 원본 상세 전체를 프런트엔드 스키마로 검증하고 JSDOM에서 코스피 942개/코스닥 1,821개 SVG 종목 링크 전환, 투자자 매매동향 17개 행, 실제 LS 수급 금액 표시를 확인했습니다. 실제 브라우저의 픽셀 단위 화면 검수는 미수행입니다. 전체 자동 검사 34개, TypeScript, 프로덕션 빌드가 통과했습니다.

## 모바일 WORKSPACE와 마감 제한

주 메뉴는 투자 관제실, 주도 섹터, 거래대금, 주도주 캘린더 4개입니다. 시세 연결·가져오기·백업은 상단 데이터 관리 버튼에 있습니다. 관제실의 지수 카드는 지수·등락률·전일 대비를 한 줄로 표시합니다. 카드를 누르면 원래 탭·스크롤을 유지하는 전체 화면 히트맵이 열리고, X/ESC로 닫습니다. 히트맵 좌표는 실제 가용 너비·높이에 맞춰 다시 계산하며 가로 스크롤을 강제하지 않습니다. 오늘의 시장 수급도 같은 전체 화면 방식입니다.

관제실은 지수/현물 수급과 핵심 순위, 섹터는 주도 섹터와 자금 흐름, 거래대금은 전체/강세 종목 및 KODEX 순위, 캘린더는 날짜별 주도주와 관찰 메모를 표시합니다. 수집 시간 변경 이전에 저장한 과거 기록은 원래 수집 시각과 함께 보존하며 새 정책의 15:30 종가로 재표기하지 않습니다.
