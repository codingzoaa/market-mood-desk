# LS증권 · Cloudflare 자동 수집

## 사용 방식

사이트를 열면 저장된 국내 시세를 자동 조회합니다. 접속 코드 입력, 연결 버튼, 연결 해제 및 예시 전환 배너는 없습니다. 브라우저는 5분마다 새 저장 시세를 조회하며 다시 보이는 시점에도 갱신합니다. 장애 때에는 검증된 마지막 정상 기록을 유지하고 오류를 표시합니다. 가상 시세로 대체하지 않습니다.

## 서버 설정

Cloudflare Worker `market-note-ls-api`에 `LS_APP_KEY`, `LS_APP_SECRET`을 Secret으로 등록합니다. 값은 GitHub와 브라우저에 넣지 않습니다. 기존 `DASHBOARD_TOKEN` Secret은 더 이상 사용하지 않으며 남아 있어도 동작에 영향을 주지 않습니다.

DB 바인딩은 `DB`, Durable Object 바인딩은 `COLLECTOR`입니다. 기존 D1 시세·수집 lease·테마 데이터와 TLS 연결 방식은 유지합니다. OAuth와 LS TR은 같은 인증서 검증 TLS 세션을 사용합니다.

## 수집 시간

한국시간 평일 09:00부터 15:30분까지 5분 간격으로 예약 수집합니다. 마지막 15:30분의 수집 이후에는 모든 국내 데이터 요청을 중단하고 저장 기록만 제공합니다. 주말 및 LS가 휴장으로 확인한 날짜는 새 거래일 기록으로 저장하지 않습니다.

Cloudflare UTC Cron:

- `*/5 0-5 * * MON-FRI`
- `0-30/5 6 * * MON-FRI`

LS·네이버 개별 요청에도 수집 시간 제한을 적용합니다. 지수 차트의 15:30 이후 봉은 제외합니다. 수집 실패 시 마지막 정상 스냅샷을 보존하며, 과거 수집 기록의 시각을 종가 시각으로 바꾸지 않습니다.

## 공개 조회 범위

`GET /api/dashboard`, `GET /api/market-details`, `GET /api/status`는 접속 코드 없이 저장 시세만 읽습니다. 공개 HTTP 조회는 LS·네이버 수집이나 수집 알람을 실행하지 않습니다. 브라우저 CORS Origin은 `https://codingzoaa.github.io`로 제한하며 이는 비밀 인증 수단은 아닙니다. 쓰기·주문·임의 TR 실행 API는 제공하지 않습니다. 앱키, OAuth 토큰, 진단 원문은 반환하지 않습니다.

수집은 사이트 접속 여부와 관계없이 Cloudflare Cron과 내부 수집 알람에서 수행합니다. 시장별 거래대금 최대100개와 순차 보강 테마를 분석하며, 히트맵은 네이버 업종 기준 종목을 사용합니다. 누락된 지표는 생성하지 않습니다.

## 모바일 화면

WORKSPACE는 국장, 주도 섹터, 거래대금, 주도주 캘린더입니다. 기준일은 제목 오른쪽 위에 배치합니다. 지수 카드를 누르면 화면 크기에 맞춘 히트맵이 열리고 X/ESC로 원래 화면에 돌아옵니다. 관심종목과 메모는 브라우저에 저장하며 시세와 분리합니다.

## 배포 및 검사

`npm test`, `npx tsc --noEmit`, `npm run build` 후 Worker와 GitHub Pages를 배포합니다. GitHub Actions는 시세 수집에 사용하지 않으며 화면 빌드·배포에만 사용합니다.

## 개인 수급과 코스피 상관관계

국장 ‘오늘의 시장’ 아래 토글에서 장 마감 기록을 조회합니다. `GET /api/correlation`은 기존 저장 기록에서 코스피 지수·일간 등락률·개인 현물 순매수만 읽고 공급자 API를 호출하지 않습니다. 지수 및 수급 각각의 asOf가 같은 거래일 15:30분이고 현재 시각이 15:31 이후인 기록만 포함합니다. 후속 업종 보강 시각으로 장중 수급을 마감 값으로 바꾸지 않습니다. 이전 마감 기록이 없으면 빈 상태를 표시합니다.

가로축은 코스피 등락률(%), 세로축은 코스피 개인 순매수(조원)입니다. 점과 아래 코스피 종가 차트의 날짜 선택을 양방향으로 연동합니다. 점선은 최소제곱 선형 추세선이고 Pearson 상관계수는 두 변수의 분산이 모두 있는 2개 이상의 표본에서 계산합니다.
