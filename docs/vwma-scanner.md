# 거가중 100선 검색기

거래대금 탭에서 LS KRX 상위 20개 일반주를 5분·60분·240분·일봉으로 비교합니다. 거래량은 jdiff_vol, 가격은 봉 종가를 사용합니다. t8412가 반환하는 장외 봉은 제외하고, 일봉도 완전한 정규장 240분봉 쌍과 별도 시초가 경매 봉(일반 13:00·15:30, 수능 14:00·16:30)의 종가와 거래량 합계로 구성합니다. native t8410 일봉에는 장외 거래가 포함되어 사용하지 않습니다. 네 프레임의 상회·하회 조합으로 초기 반등, 단기/중기 전환, 상승 정렬, 눌림목 등을 분류합니다. 결측은 미확인이며 하락으로 분류하지 않습니다.

장중 기존 시세·수급 수집이 끝난 경우에만 공유 LS 세션을 사용해 5분 슬롯당 최대 5종목을 순환 조회합니다. 전체 순환은 약 20분이며 개별 조회 시각을 표시합니다. HTTP GET은 저장값만 읽으며 조회를 유발하지 않습니다. 최신 당일 분봉과 당일 일봉을 제외하며 돌파 시각은 체결 시각이 아닌 LS 봉 표기입니다. 명시적인 수정비율이 있는 가격은 재검토 전까지 제외합니다. jongchk의 일반 상태 비트를 기업행사로 간주하지 않습니다.

배포 후 장외 시간에 CI가 서명한 일회용 요청으로 직전 마감 거래일의 최대 20종목을 초기화합니다. 장중에는 실행하지 않습니다. 이 절차는 신규 권한·주문·알림 발송 없이 기존 읽기 전용 차트만 조회합니다. 과거 저장값은 실시간 신호와 구분합니다. N분 요청이 다른 간격으로 반환되면 CHART_INTERVAL_MISMATCH로 차단하며 모든 프레임의 100봉 이상 계산을 배포 검증에서 확인합니다.

수능일 2026-11-19는 LS 장시간 봉의 표준 마감 구간이 혼재하므로, 해당 거래일의 실제 5분봉을 한 번 저장하고 10:00 개장·16:30 마감 기준으로 60/240분봉을 다시 묶습니다. 거래량 합계와 마지막 종가를 보존하며 그 날짜를 삭제하거나 추정값으로 채우지 않습니다.

## 텔레그램 전환 알림

기존 TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID 수신처로 검색기 조회 대상 20종목의 단기 전환·중기 전환·상승 정렬 신규 진입, 상승 정렬 이탈을 알립니다. 관심종목 한정이 아니며 UI 필터와 독립적입니다. 상승 정렬에서 중기/단기 전환으로 내려오면 이탈 한 건만 보냅니다. LS 세션이 닫힌 후 기존 수집 알람에서 처리하며 HTTP GET과 과거 초기화에서는 발송하지 않습니다.

동일 거래일에 25분 이내의 두 유효한 조회를 비교하고, 5분 이내에 수집한 결과만 처리합니다. 최초/다음날 첫 관측, 결측 복구, 오래된 관측 및 장외 자료는 기준만 설정하거나 제외합니다. 종목별 순환 주기는 약 20분이므로 분봉마다 즉시 감지하는 기능은 아닙니다. D1에 전환 이벤트와 발송 선점 상태를 저장하여 같은 전환을 중복 발송하지 않습니다. Telegram이 수신했는지 불분명한 타임아웃은 uncertain으로 남기고 자동 재발송하지 않습니다. 명시적인 발송 거부는 failed로 남깁니다. 이 경우 해당 알림이 누락될 수 있습니다.

/api/vwma-scanner 응답의 alerts에는 활성 여부, 대상 조건, 마지막 검사 및 발송/실패/미확인 수만 표시하며 토큰·채팅 ID·원문 오류를 노출하지 않습니다. 배포 확인에는 이 상태만 사용하고 실거래 신호를 흉내 낸 테스트 메시지는 보내지 않습니다.
