# Operations, provenance and common classifications

The data-management screen shows actual GitHub collection, validation and deployment runs alongside the read-only Worker collection status. The calendar includes its own invocation/retry history and scheduled KST time (including the market-session exception). Calendar PR creation, independent CI, merge and Pages deployment are separate guarded steps. A successful job never implies a skipped Pages deployment succeeded; the dashboard displays each job and failed step independently.

`operations-status.yml` snapshots GitHub REST run/job metadata after relevant workflows and at :19/:49 UTC every hour. It refreshes Pages explicitly because GITHUB_TOKEN commits do not generate ordinary push events. Pages completion is deliberately excluded from the monitor's triggers to avoid a feedback loop. The UI polls the published snapshot every minute and marks snapshots older than 75 minutes. The observed timestamp is the metadata retrieval time, not the source-data time or a deployment receipt for the snapshot's own publication. Missing records and failed fetches remain unknown, not success. Public records contain no tokens or logs.

Signal charts display source, provisional/validated status, actual date range, valid-value count, missing-value count and last valid date. Missing counts concern values in received rows; absent exchange sessions are not inferred to be zero or complete. Filtered/excluded breadth values are missing. Sample breadth membership and provisional history remain unchanged.

All main views now render the same published classification registry. Browser edits and imported old edits are retained as drafts, displayed in the map and never applied to rankings or historical calendar cards until owner-confirmed common publication. The existing GitHub owner identity gate is unchanged. Each common save/reset appends before/after provenance and a persistent symbol revision; even resets retain a tombstone revision so stale requests cannot resurrect removed changes. Conflicted drafts open the latest common classification for review. History begins with new changes; old changes are not fabricated.

Market-signal charts and drawdown charts share zoom-in/out, previous/next range and full-range controls. Market signals retain their shared latest-date period presets. The two correlation plots share their visible sample window, wheel zoom and pointer panning. ECharts retain their linked axes, dataZoom and visible-price-axis fitting. Navigation changes the view; it does not recalculate a drawdown's selected analysis horizon.
